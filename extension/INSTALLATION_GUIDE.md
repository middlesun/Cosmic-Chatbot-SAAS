# 🚀 Quick Installation Guide

## Step 1: Generate Icons
1. Open `create_icons.html` in your browser
2. Right-click each icon and save as:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`
3. Save these files in the `Toot-Tester-Plugin` folder

## Step 2: Install Extension
1. Open Chrome and go to `chrome://extensions/`
2. Enable "Developer mode" (top right toggle)
3. Click "Load unpacked"
4. Select the `Toot-Tester-Plugin` folder
5. The extension will appear in your toolbar

## Step 3: Get API Key
1. Go to [OpenRouter.ai](https://openrouter.ai)
2. Sign up for free account
3. Get your API key from the dashboard
4. Copy the key

## Step 4: Configure Extension
1. Click the extension icon in Chrome
2. Go to "Setup" tab
3. Enter your API key
4. Click "Save API Key"

## Step 5: Test Forms
1. Open websites with forms in multiple tabs
2. Click the extension icon
3. Go to "Test" tab
4. Click "Start Testing All Tabs"
5. View results in "Results" tab

## ⚠️ Important Notes
- Only test websites you own or have permission to test
- The extension makes real form submissions
- Some forms may fail due to security measures (CAPTCHA, etc.)
- Be mindful of API usage limits

## 🔧 Troubleshooting
- Make sure all icon files are present
- Check that API key is valid
- Verify extension permissions are granted
- Look for error messages in browser console

Happy Testing! 🎉
